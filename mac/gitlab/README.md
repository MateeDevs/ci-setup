# Matee CI - macOS - GitLab

Follow the [macOS installation guide](https://docs.gitlab.com/runner/install/osx/)
and [register the runner](https://docs.gitlab.com/runner/register/) with your
GitLab instance.

Run the service under the macOS account that has access to the simulator and
the signing keychain. GitLab Runner runs as a user LaunchAgent on macOS.
